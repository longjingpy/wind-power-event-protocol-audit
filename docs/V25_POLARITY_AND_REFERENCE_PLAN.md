# v25：隔离极性增量，并分开评价真人与AI参考

## 问题与验收

主问题：在相同方向、幅度、持续时间、起始功率和前窗功率控制下，受保护极性是否额外改善独立风过程的样本外概率识别？比较必须使用相同事件、源训练、验证预算和目标切分。结果可支持独立信息增量，也可支持“恢复编码丢失的标量方向”这一机制；以实测结果决定。

- 主增量矩阵：S、S+GAF/PCA5、S+bit、S+GAF/PCA5+bit。附GAF/PCA6维数控制、PCA前signed channel、raw25、既有standalone GAF/bit路线。
- 区间：同事件配对、同场日历7日块、2,000次；报告AUROC差、log-loss差、Brier差及有效块数。3/14日为敏感性。LiDAR两仪器的原最终窗口保持不变，有效7日块为4；不把重采样次数当独立证据数。
- 负对照：事件间独立随机bit；测试时错误bit；一致反号作为可逆重编码控制而非信息破坏；只在PCA前加入signed channel；内部最大幅值、事件终点和上下文坐标符号。
- 噪声：有效归一化形态的最大绝对坐标恒为1，因此“接近0”应在归一化前振幅尺度上检查。测试不同噪声/幅度比、正负极值近乎并列时的anchor符号翻转和概率性能；不从测试结果倒选噪声条件。
- 既有摘要的结构结论添加matched/encodable条件；Methods区分历史主分析与本轮审稿后探索性机制扩展，不能补写成事先预注册。
