## 主文现在回答什么

1. **能否节省有政策依据的费用？** 原生15分钟数据、2022版江苏准确率条款和验证期选型下，15分钟费用下降3.76%；四小时下降18.22%，节省27,109.50元，七日块95%区间15.43%–21.38%。这是条款组件的费用模拟，非实缴账单。
2. **为什么不能只看nMAE？** 同一raw25概率模型、相同输入和0.75混合权重，只改变输出行动，四小时费用下降10.54%，节省14,726.58元，尽管平均绝对误差升高。此为固定模型行动消融，不是事后重新选择全局最优模型。
3. **收益集中在哪里？** 四小时高变化点占32.95%，贡献72.38%的persistence规则费用。全期节省已计入新增超限收费，未只取有利时间段。
4. **储能是否可以有正向运行收益？** 新英国预测驱动控制在91完整日、10%功率/2小时配置下，事件信息臂扣除模拟退化费后增益5,986.77英镑；市场信息基线7,168.89英镑。二者是固定资产的运行收益，资本收益另计。
