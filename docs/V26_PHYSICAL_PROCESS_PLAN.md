# v26：由单一极性修补转向完整物理过程与条件时序增量

## 目标和增益门槛

用户要求重新设计并实际运行，而非继续包装v25的小增量。暂停v25投稿包发布；原结果、已完成的7组AI评阅及v24经济结果保持原样。

科学问题：相同端点变化与标量描述下，时间顺序、曲率和往返过程能否提升独立实测风过程的重建？这属于回顾性物理识别；未来风/功率预测仍使用起报时信息，不能混称。

本轮提前固定实用性门槛：相对验证选择的最强标量基线，完整风速变化轨迹RMSE降低至少10%，并报告配对7日区间；希望至少两组独立仪器/场站测试支持同方向。该数值是验收目标，不是承诺或筛选规则。所有总体和对照保留。旧端点任务保留为历史锚点，新过程任务不冒充旧任务已得到更大增量。

## 任务与数据

- Hill 2026 T11/T07和SMARTEOLE的现有同步功率、独立LiDAR/WindCube。
- 既有30分钟事件协议，纳入primitive和compound；同协议配对规则建立matched资格。
- 对同一机组、同一起止区间去重，保留是否存在compound及检测来源，避免相同区间重复加权。
- 主要事件为60–240分钟，至少7个连续有效10分钟风观测；不跨风观测缺口插值。
- 在事件内17个相对时刻重建风速相对起点的变化，单位m/s。主评分对后16点取事件级MSE，再平均开方；同时评价去除端点连线后的过程形状、最大drawup/drawdown和往返事件。
- 过程标签从独立风观测确定：drawup/drawdown分别是否达到1.5 m/s，构成弱变化、上升主导、下降主导、往返四类。阈值沿用已知风变化尺度，不按结果选择。
- Hill保留3月14日/4月7日时间分割及完整前后上下文约束；SMARTEOLE按原始观测日历60/20/20分割，所有机组共享切分。
- 这些日历之前已用于其他分析，因此本轮是新的探索性任务，不标为新获取确认集。

## 预先固定矩阵

所有新增表示均和同一组强标量信息组合。保留原S5；S19补充范围、总变化、曲率、最大变化率、前后均值、形态尺度、峰谷位置、均值/标准差和带符号弦残差。原始25点形态是强信息参照。

| 表示 | 目的 |
|:--|:--|
| S5、S19 | 原控制与增强标量控制 |
| raw25、raw/PCA6、raw/PCA12 | 完整时间顺序与压缩强基线 |
| GASF/PCA6、GASF5+bit | 保留旧编码路线 |
| GADF/PCA6 | 正式差分场对照 |
| 通道平衡GASF+GADF/PCA6 | 同时保留偶对称几何与奇对称方向 |
| 通道平衡GASF+raw/PCA6 | 检验原signed-channel的维数/能量失衡 |
| GASF3+有符号DCT3；GASF6+DCT6 | 固定维数保护低阶趋势、曲率与时序 |

GASF/GADF依据Wang与Oates (2015), https://arxiv.org/abs/1506.00327；属于既有文献编码，不称新发明。对于本文起点坐标为0的归一化形态，GADF的起点行可恢复原形态（按所实现符号约定），用合成测试核验；压缩后的保留程度实测评价。

解码器采用相同的多输出ExtraTrees及正则化线性回归预算；标准化、PCA和通道能量仅在训练数据拟合。每种表示按验证轨迹MSE选配置，保留全部候选。先生成validation锁定记录，再读取测试性能。

## 直接隔离条件增量

若基本矩阵仍不能形成足够清晰的实用增量，执行已定义的加性残差路线：用强标量模型预测风过程，再用时序表示预测其剩余误差。训练残差由带时间清洗的日历交叉拟合产生。设置同预算的“标量残差修正”对照，区分增加模型容量和真正新增时序信息。修正强度只在验证集选择，包含零修正选项。

## 核验和停止点

### 测试解锁前的验证期设计更新

首轮仅查看验证损失，尚未打开v26测试结果。加入如下预先记录的扩展：

1. 恢复起始功率和幅度后的完整功率轨迹、立方根功率基函数及其训练期PCA；相应强标量基线S27也获得同一物理变换的分布摘要。立方根是输入特征，不是风观测替代标签。
2. 在固定30分钟事件边界和独立风目标下，额外恢复10分钟功率表征，所有标量和形态方法均使用同样的10分钟观测。该实验检验观测时间支持，而非用高分辨率方法对抗低分辨率基线。
3. 加性残差训练采用最多5个连续日历块折，并清除完整上下文重叠。标量残差和形态残差使用同一8种解码器及0/0.25/0.5/1修正强度；全部仅由验证损失选定。

旧30分钟候选及验证记录保留；新原生轨道为同目录下独立native10数据集。若原生质量造成样本变化，明确计数并限制跨分辨率比较到共同事件。测试后不再在本版本重选模型或时间尺度。

训练变换不读取测试；不改变真实风标签以提高分数；相同测试事件与评分总体；所有增益均相对强标量及原始轨迹参照报告。风场机组共享日历块，区间有效块数必须显示。新增结果进入outputs/protocol_benchmark_v26；只有运行和核验完成的结果进入稿件。
