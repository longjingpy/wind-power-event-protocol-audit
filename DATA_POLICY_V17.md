# Processed-data distribution policy

The data provider permits research use and release. The current distribution decision is to publish de-identified processed datasets rather than original provider files.

The former v0.2.0 data release has been moved to a non-public draft while the processed replacement is prepared and checked. Its assets have been retained, not deleted. Earlier downloads cannot be recalled. The code repository and aggregate analysis results remain public.

The replacement will use stable study identifiers, retain the scientific variables and quality flags required for evaluation, and exclude original turbine names, direct location fields and unrelated personal material. A documented identifier/time policy and reproducibility checks must accompany the processed bundle. Availability will be announced only after the actual files and download entry points have been verified.

Original third-party data and software licences remain applicable. Authorization and distribution are separate decisions: authorization to release originals does not mean that this repository will continue to serve them.
